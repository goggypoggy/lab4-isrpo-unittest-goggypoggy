# Общее описание geometric_lib

Данное решение представляет собой библиотеку различных функций для работы с геометрическими объектами.\
Реализованы следующие функции:
- **периметр** объекта;
- **площадь** объекта;

На данный момент поддерживаются следующие геометрические фигуры:
1. Круг
2. Квадрат
3. Прямоугольник
4. Треугольник

# Функции в geometric_lib

## Круг

- `area(r)`

  Возвращает площадь круга данного радиуса.\
  Считается по формуле **S = πR<sup>2<sup/>**.
  
  Параметры:
  * `r (float)` - *радиус* круга

  Возвращаемое значение:
  * `area (float)` - *площадь* круга

  Пример использования:
  ```
  radius = 3
  a = area(radius)
  print(a) // 28.274...
  ```

- `perimeter(r)`

  Возвращает периметр круга данного радиуса.\
  Считается по формуле **P = 2πR**.
  
  Параметры:
  * `r (float)` - *радиус* круга

  Возвращаемое значение:
  * `perimeter (float)` - *периметр* круга

  Пример использования:
  ```
  radius = 3
  p = perimeter(radius)
  print(p) // 18.849...
  ```

Все вышеперечисленные функции описаны в [circle.py](../circle.py).

## Квадрат

- `area(a)`

  Возвращает площадь квадрата с данной стороной.\
  Считается по формуле **S = a<sup>2<sup/>**.
  
  Параметры:
  * `a (float)` - *длина стороны* квадрата

  Возвращаемое значение:
  * `area (float)` - *площадь* квадрата

  Пример использования:
  ```
  side = 2

  print(a) // 4
  ```

- `perimeter(a)`

  Возвращает периметр квадрата с данной стороной.\
  Считается по формуле **P = 4a**.
  
  Параметры:
  * `a (float)` - *длина стороны* квадрата

  Возвращаемое значение:
  * `perimeter (float)` - *периметр* квадрата

  Пример использования:
  ```
  side = 2
  p = perimeter(side)
  print(p) // 8
  ```

Все вышеперечисленные функции описаны в [square.py](../square.py).

## Прямоугольник

- `area(a, b)`

  Возвращает площадь прямоугольника с данными размерами.\
  Считается по формуле **S = ab**.
  
  Параметры:
  * `a (float)` - *длина первой стороны* прямоугольника
  * `b (float)` - *длина второй стороны* прямоугольника, смежной первой

  Возвращаемое значение:
  * `area (float)` - *площадь* прямоугольника

  Пример использования:
  ```
  width = 3
  height = 5
  a = area(width, height)
  print(a) // 15
  ```

- `perimeter(a, b)`

  Возвращает периметр прямоугольника с данными размерами.\
  Считается по формуле **P = 2(a+b)**.
  
  Параметры:
  * `a (float)` - *ширина* прямоугольника
  * `b (float)` - *высота* прямоугольника

  Возвращаемое значение:
  * `perimeter (float)` - *периметр* прямоугольника

  Пример использования:
  ```
  width = 3
  height = 5
  p = perimeter(width, height)
  print(p) // 16
  ```

Все вышеперечисленные функции описаны в [rectangle.py](../rectangle.py).

## Треугольник

- `area(a, h)`

  Возвращает площадь треугольника с данными размерами.\
  Считается по формуле **S = 1/2 * ah**.
  
  Параметры:
  * `a (float)` - *длина основания* треугольника
  * `h (float)` - *длина высоты* треугольника, опущенной на это основание

  Возвращаемое значение:
  * `area (float)` - *площадь* треугольника

  Пример использования:
  ```
  AC = 3
  BH = 4
  a = area(AC, BH)
  print(a) // 6
  ```

- `perimeter(a, b, c)`

  Возвращает периметр треугольника с данными размерами.\
  Считается по формуле **P = a + b + c**.
  
  Параметры:
  * `a (float)` - *длина первой стороны* треугольника
  * `b (float)` - *длина второй стороны* треугольника
  * `c (float)` - *длина третьей стороны* треугольника

  Возвращаемое значение:
  * `perimeter (float)` - *периметр* треугольника

  Пример использования:
  ```
  AB = 4
  BC = 5
  AC = 3
  p = perimeter(AB, BC, AB)
  print(p) // 12
  ```

Все вышеперечисленные функции описаны в [triangle.py](../triangle.py).
